# Contributing

Thanks for helping improve this skill.

## Ways to help

- **Report a problem:** open an issue with what you asked Claude, what you expected, and what you got.
- **Suggest a rule or check:** open an issue describing the SEO case, with a real example URL if you can share one.
- **Send a fix:** fork the repo, edit `skills/amoo-ehsan-seo/SKILL.md` or the README, and open a pull request with a short explanation.

## Guidelines

- Keep instructions practical: what to change, where, and how to measure it.
- Persian text should read naturally, not like a machine translation.
- Do not include client data, credentials or private URLs in issues or pull requests.

Issues and pull requests can be written in English or Persian.
